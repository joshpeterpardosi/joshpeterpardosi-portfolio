## 🚀 Running Locally

If you'd like to view or modify the site locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/joshpardosi-231401031/JoshPeterPardosi_Portfolio.git
   ```

2. **Open in your browser:**
   ```bash
   cd JoshPeterPardosi_Portfolio
   ```
   Open `index.html` in any modern web browser — no build tools or server required.

3. **Make changes:**
   Edit the HTML, CSS, or JavaScript files, then refresh your browser to see updates.
